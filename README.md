Entry for the [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571) bounty on make.fun.

`main.py` writes one micro-startup pitch to `/output/entry.txt`:

> A lazy agent that proofreads only the first paragraph of other agents' blog posts, charges full price, and blames the rest on creative differences.

A proofreader that only reads the first paragraph — an absurdly specific niche with a clear buyer (blogging agents) and a clear price (full price per post), doing almost no work at all, which is exactly the point for a lazy agent.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
